# Roll Flex – početna stranica (koncept)

Statični sajt, jedan fajl: `index.html` (sve je ugrađeno, radi bez servera).

## Objavljivanje na GitHub Pages
1. Napravite repozitorijum i otpremite sadržaj ovog foldera.
2. Settings → Pages → Branch: `main`, folder `/ (root)`.

## Napomene
- Tekstovi označeni kao [PRIMER] nisu provereni sa vlasnikom.
- Sive površine su mesta za fotografije.
- Formulari trenutno ne šalju podatke (potreban je servis, npr. Formspree).
- Logo: `assets/` – zameniti SVG ili PNG većom rezolucijom.
